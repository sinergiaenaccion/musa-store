# MUSA — More than a shop, a vibe. ♡

MUSA is a custom-built ecommerce storefront for Córdoba, Argentina.

## Direction

- Custom frontend — no Tiendanube template.
- Mobile-first and responsive.
- Teen lifestyle / cute finds / beauty / tech / accessories.
- Curated discovery: **MUSA PICKS** and **NEW DROP**.
- Checkout prepared for Mercado Pago.
- WhatsApp and social channels will be connected as the store moves toward launch.
- Legal pages and policies will be added before production checkout.
