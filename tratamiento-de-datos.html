Tratamiento de datos

Los datos que proporciones para MUSA CLUB podrán utilizarse para administrar la membresía, validar beneficios, enviar novedades y promociones cuando corresponda, prevenir usos indebidos y generar estadísticas generales para mejorar la experiencia.

No se solicitarán datos sensibles como requisito para participar del Programa. El tratamiento se realizará de acuerdo con la legislación vigente y con criterios de proporcionalidad y seguridad.

Podés retirar el consentimiento para comunicaciones comerciales en cualquier momento. La baja de comunicaciones no elimina los datos que MUSA deba conservar por obligaciones legales o para acreditar una operación.
